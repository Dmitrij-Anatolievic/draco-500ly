# Draco at 500 Light-Years

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.19319995.svg)](https://doi.org/10.5281/zenodo.19319995)

**EXPLORATORY RESEARCH — hypothesis-generating, not hypothesis-testing.**

A 2017 acrylic painting, derived from recurring dreams, encodes the geometry 
of the Draco constellation as seen from ~541 light-years in the direction of 
Cygnus (d=0.4453, p=0.0000, five independent validation tests).

## Main result

Five independent chromatic sets all converge in RA 240–290° (Cygnus/Draco):

- **BLUE** (16 nodes): Draco d=0.4453, p=0.0000 — 541 light-years
- **GREEN** (8 nodes): Draco field stars d=0.2916, p=0.0003
- **ORANGE** (8 nodes): Lyra d=0.0711
- **COMET** (1 element): d=0.012 from Lyra cluster, tail toward Dec=+72°

Gaia DR3 corridor: 1,119 G/K stars, 10 solar twins, zero known exoplanets.

## Repository structure

- `blind_test_88.py` — main 15-constellation blind Procrustes test
- `gaia_draco_query.py` — Gaia DR3 ADQL query for the stellar corridor
- `gwen_validation.py` — five-test validation battery
- `sphere_map.py` — complete spherical sky map (46,512 combinations)
- `analisi_dipinti_v2.py` — chromatic segmentation and node extraction
- `dati/` — node coordinates, Gaia DR3 solar twin IDs
- `cifre/` — all figures generated by the scripts
